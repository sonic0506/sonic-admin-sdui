# 컴포넌트 유형별 스토리 체크리스트

컴포넌트에 해당하는 유형을 모두 찾아 항목을 합친다 (예: 데이터를 불러오는 폼 = 폼 + 비동기).
**필수** 항목은 해당되면 반드시 만든다. **권장** 항목은 의미 있을 때 만들고, 생략했다면 보고에 이유를 적는다.

## 공통 (모든 컴포넌트)

- **필수** `Default` — 필수 props만으로 렌더링
- **권장** 열거형 props(variant, size 등)의 각 값 — 값이 많으면 한 스토리에 모아 보여주는 방식도 가능
- **권장** `Disabled` / `ReadOnly` — 해당 prop이 있을 때

## 텍스트·콘텐츠를 표시하는 컴포넌트

- **권장** 긴 텍스트 (줄바꿈, 말줄임 확인)
- **권장** 빈 값 또는 최소 콘텐츠
- **권장** 다국어 텍스트 (프로젝트가 i18n을 쓰는 경우)

## 버튼·토글·링크 등 단일 상호작용

- **필수** 클릭 시 콜백 호출 검증
- **필수** 비활성 상태에서 클릭해도 콜백이 호출되지 않음 (disabled 지원 시)
- **권장** 키보드(Enter/Space)로 동작
- **권장** 로딩 상태 (loading prop이 있을 때)

## 입력·폼

- **필수** 정상 입력 후 제출 → 콜백이 올바른 값으로 호출됨
- **필수** 유효성 검사 실패 → 에러 메시지 노출, 제출 콜백 미호출
- **권장** 필수값 누락 상태로 제출
- **권장** 초기값이 채워진 상태 (수정 폼)
- **권장** 제출 중 상태 (중복 제출 방지)
- **권장** 서버 에러 응답 처리

## 비동기 데이터를 불러오는 컴포넌트

- **필수** `Loading`
- **필수** `Success` (정상 데이터)
- **필수** `Error` (요청 실패)
- **필수** `Empty` (빈 목록·데이터 없음) — 해당 UI가 있을 때
- **권장** 재시도 동작 (재시도 버튼이 있을 때)

## 목록·테이블

- **필수** 여러 항목
- **필수** 빈 목록
- **권장** 항목 1개
- **권장** 많은 항목 (스크롤, 페이지네이션, 가상화)
- **권장** 정렬·필터·선택 동작 (있을 때 인터랙션 테스트)

## 오버레이 (Dialog, Modal, Popover, Dropdown, Tooltip, Toast)

- **필수** 열기 동작 → 내용 표시 검증
- **필수** 닫기 동작 (닫기 버튼, Esc, 바깥 클릭 중 지원하는 것)
- **권장** 열릴 때 포커스가 오버레이 안으로 이동, 닫힐 때 트리거로 복귀
- portal로 렌더링되면 캔버스 바깥(document body)에서 찾아야 한다 → `testing-rules.md`

## 탭·아코디언·스텝 등 상태 전환

- **필수** 전환 동작 → 해당 패널 표시 검증
- **권장** 키보드 탐색 (방향키 등, 컴포넌트가 지원할 때)

## 권한·인증에 따라 달라지는 컴포넌트

- **필수** 권한별(로그인/비로그인, 역할별) 상태
- 인증 상태 주입은 프로젝트의 기존 decorator·mock을 우선 사용

## 페이지·대형 조합 컴포넌트

- 스토리는 최소화한다. 대표 상태(정상, 로딩, 에러) 위주로 두고, 세부 상호작용은 하위 컴포넌트 스토리에서 검증한다.
- 여러 화면을 오가는 흐름은 스토리가 아니라 E2E 테스트 영역이다.
